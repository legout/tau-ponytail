# Issue tracker

Tracker: [GitHub Issues](https://github.com/legout/tau-ponytail/issues).

GitHub issues are the canonical task bodies. Use `gh issue view`, `gh issue list`, and `gh issue edit` to read and manage them. Every ticket references its authoritative specification, ADRs, and execution plan.

The Tau Ponytail v1 sequence is [#1–#5](https://github.com/legout/tau-ponytail/issues), ordered by the dependency map in [`docs/plans/tau-ponytail-v1.md`](../plans/tau-ponytail-v1.md).
